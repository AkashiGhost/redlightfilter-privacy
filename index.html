Privacy Policy

RedLightFilter: night light · Effective 27 July 2026

RedLightFilter: night light is developed by Akash Manmohan. This release is a local UI preview.

Data collection and sharing

This app does not collect, store, transmit, sell, or share personal or sensitive user data. It has no accounts, ads, analytics, payment SDK, or third-party data-collection SDK, and it requests no network permission.

Local app data

The preview runs from files included in the app. The developer receives no user data. Any app data held locally by Android can be removed through Android's app-storage controls or by uninstalling the app.

Data safety

  • No data is collected.
  • No data is shared with third parties.
  • No account is required.
  • No advertising ID is used.

Current functionality

The controls simulate red-light, extra-dim, mode, and scheduling interfaces. This build does not apply a system-wide screen filter or run background schedules.
